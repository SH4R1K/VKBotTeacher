# VKBotTeacher

Локальный помощник учителя. Загружаете методички в формате PDF, приложение
разбирает их структуру, просит у ИИ написать по каждому занятию сообщение для
родителей и рассылает результат в беседы ВКонтакте — или просто кладёт текст в
буфер обмена.

Всё работает локально: свой сервер на `127.0.0.1`, никаких внешних хранилищ.
Наружу уходят только запросы к API ВК и к выбранному провайдеру ИИ.

## Возможности

- **Загрузка PDF** — перетаскиванием в окно или кнопкой. Методички складываются
  в `lessons/`, фотографии — в `photos/`. Отметить методичку можно кликом по строке,
  а кнопкой справа она открывается в системном просмотрщике.
- **Разбор методички** — вытаскиваются тема, резюме, образовательные результаты и
  этапы занятия с задачами по времени. Если структура не распозналась, в промпт
  уходит полный текст занятия.
- **Генерация сообщений** — по одному занятию или сразу пачкой, стиль текста
  задаётся в редактируемом файле `style.md`.
- **Предпросмотр и вложения** — фотографии показываются карточками с миниатюрами,
  листаются в полном размере, прикрепляются к сообщению (до 10 за раз). Список
  постраничный и отсортирован от свежих к старым.
- **Рассылка в беседы ВК** — режимы: токен сообщества, токен пользователя или
  буфер обмена. Список бесед подтягивается из ВК прямо в настройках.
- **История** — каждое отправленное или сохранённое сообщение попадает в
  `history/`: поиск по тексту, постраничный просмотр, удаление записей.
- **Настройки без перезапуска** — провайдер ИИ, модель, токены, режим отправки и
  список чатов правятся в вебе; сервер пересоздаёт клиента и отправителя сам.
- **Контроль доступа к ИИ** — сервер сам проверяет провайдера, состояние видно в
  шапке, а генерация не запускается, пока провайдер недоступен. Модель выбирается
  из списка моделей провайдера, температура — ползунком.
- **Светлая и тёмная тема** — переключается кнопкой в шапке, выбор запоминается в
  браузере.
- **Черновик** — несохранённый текст переживает перезагрузку страницы и чистится
  после успешной отправки или сохранения.
- **Горячие клавиши** — `Ctrl+Enter` отправить, `Ctrl+Shift+Enter` перегенерировать,
  `Ctrl+S` сохранить, `Ctrl+K` поиск методичек, `Ctrl+H` история, `?` — весь список.

## Требования

- Python 3.11+ (проверено на 3.14). Из-за `tomllib` в стандартной библиотеке
  готовые сборки 3.10 и ниже не подойдут.
- Зависимости из `requirements.txt`: `aiohttp`, `pydantic`, `pypdf`, `Pillow`
  и `requests` — последний нужен только для `test_vk_token.py`.

```bash
pip install -r requirements.txt
```

Ни сборки, ни фронтового бандлера нет: `web/` отдаётся как есть.

## Запуск

```bash
python app.py
```

Сервер поднимается на `127.0.0.1:8765` и сам открывает браузер. Адрес и порт
меняются в `[server]` файла `config.toml`.

## Настройка

Файл `config.toml` лежит рядом с `app.py`. В репозиторий он не попадает
(см. `.gitignore`) — при первом запуске приложение создаёт его само, с настройками
по умолчанию и подсказками в комментариях. Дальше его можно править руками, но
чаще всего это не нужно: провайдер ИИ, токены, режим отправки и список бесед
правятся в диалоге «Настройки», который сам пишет файл и применяет изменения без
перезапуска. Каждое сохранение кладёт рядом `config.toml.bak` — это автобэкап с
секретами, в репозиторий ему не место.

Состав файла:

```toml
[llm]
provider = "lm_studio"        # lm_studio | ollama | openai | gigachat | custom
base_url = "http://localhost:1234/v1"
api_key = "lm-studio"
model = "gemma-3-12b-it"
temperature = 0.7
timeout_seconds = 180
max_tokens = 1200

[transport]
mode = "community"            # community | user_token | clipboard

[vk]
community_token = "СЕКРЕТ_ТОКЕНА_СООБЩЕСТВА"
user_token = ""
api_version = "5.199"

[server]
host = "127.0.0.1"
port = 8765

[paths]
photos_dir = "photos"
history_dir = "history"
lessons_dir = "lessons"
style_file = "style.md"

[[chats]]
name = "Название беседы"
peer_id = 2000000000
```

### Про провайдера ИИ

- Пока провайдер отвечает, в шапке горит «ИИ: доступен». Сервер опрашивает его
  сам раз в 15–20 секунд, а перед генерацией проверяет ещё раз: если доступа
  нет, таймер не запускается, а кнопки генерации заблокированы.
- Список моделей подтягивается из самого провайдера. У локальных (LM Studio)
  он шире, чем в OpenAI-совместимом `/v1/models`, — там видны и ещё не загруженные
  модели; в списке они помечены отдельно.
- Смена адреса или ключа сразу перезапрашивает список. Пустой список — значит
  провайдер недоступен, ключ неверный или адрес указывает не туда.

### Про токены ВК

- **Токен сообщества** надёжнее: он пишет от имени сообщества, и участники видят
  сообщение от него.
- **Токен пользователя** пишет от вашего личного аккаунта.
- Если ключ сообщества создан без галочки «доступ к фотографиям», текст
  отправляется, а фото — нет: ВК отвечает кодом 15. Это лечится только
  пересозданием ключа с этой галочкой.
- ID беседы (`peer_id`) у сообщества и у человека **разные**, хотя это одна и та же
  беседа. Поэтому беседы проще добавить кнопкой «Загрузить беседы из ВК» —
  приложение найдёт их перебором и отметит те, что уже есть в списке.
- В режиме сообщества беседы, куда сообщество не добавлено, недоступны: ВК
  отвечает 917. Такие чаты лучше убрать из рассылки, иначе отчёт о неудаче
  придёт по каждому из них.

### Про стиль сообщений

`style.md` — обычный текст с примером того, как должно звучать сообщение для
родителей. Если в нём есть строка `{{ДАННЫЕ ЗАНЯТИЯ}}`, она заменяется данными
разобранного занятия (тема, резюме, результаты, этапы с задачами). Если такой
строки нет, данные просто добавляются в конец. Файл редактируется прямо в вебе.

## Структура проекта

| Путь | Что внутри |
| --- | --- |
| `app.py` | Точка входа: HTTP-роуты, разбор запросов, сборка JSON-ответов |
| `core/` | Логика без знания о вебе: конфиг, разбор PDF, промпты, ИИ, ВК, история, миниатюры |
| `sender/` | Отправка: `VKSender` для ВК и `ClipboardSender` для режима «в буфер» |
| `web/` | Фронтенд: `index.html`, `app.js`, `theme.css` (токены и темы), `style.css` (компоненты), без сборки |
| `lessons/`, `photos/`, `history/` | Загруженные методички, фотографии и сохранённые сообщения |
| `test_vk_token.py` | Скрипт для проверки токена в терминале |

Правила разработки и известные грабли описаны в `AGENTS.md`.

## Проверка

Тестового фреймворка в проекте нет. Линт и синтаксическая проверка фронта:

```bash
python -m ruff check .
node --check web\app.js
```

Живой токен ВК проверяется отдельно:

```bash
python test_vk_token.py                # только прочитать токен
python test_vk_token.py --send 20000  # и отправить тестовое сообщение в беседу
```

## Ограничения

- Приложение однопользовательское и слушает только `127.0.0.1` — авторизации нет.
- Удаление фото и записей истории необратимо.
- Поиск по методичкам и фотографиям работает в браузере; серверный поиск есть
  только по истории.
- Рассылка идёт в пределах одного аккаунта: за день ВК ограничивает число
  сообщений в один часовой беседе.
