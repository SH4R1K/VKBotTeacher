            Провайдер ИИ

            Выбор провайдера подставляет его адрес и ключ. Локальные (LM Studio, Ollama) работают без ключа и без интернета, облачные требуют ключ. Поле модели подсказывает список моделей, если провайдер его отдаёт.

            Названиеpeer_id
            peer_id нужен только для отправки через API. Без него сообщение копируется в буфер, а ты вставляешь его в беседу сам. ВК не отдаёт список бесед, куда добавлен бот, поэтому в поле peer_id можно вставить ссылку из браузера (vk.com/im?sel=2000000000) — приложение само вытащит число.

            Беседы ВК

            Отметь нужные и нажми «Добавить в рассылку».
